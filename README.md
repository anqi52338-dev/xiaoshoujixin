# xiaoshoujixin · 草莓小手机 🍓

浅粉色 ins 风的 AI 小手机，单文件网页：直接用浏览器打开 `index.html` 就能用（手机上会全屏显示）。

## 功能
- **微信**：聊天、通讯录（自定义 AI 角色：头像 / 人设 / 开场白）、朋友圈（好友会用 AI 评论）、我
- **日历**：月视图、彩色日程、即将到来的提醒、会显示经期
- **生理期**：周期圆环、下次经期预测、易孕期 / 排卵日、历史记录、周期和经期长度设置
- **记账**：收入 / 支出、可爱的分类、月度汇总、分类占比
- **便利贴**、**心情日记**、**喝水打卡**
- **设置**：个人资料、AI 接口（兼容 OpenAI 格式：地址 / Key / 模型 / 温度 / 上下文条数）、8 款壁纸、数据导出 / 导入 / 清空

没有填 API Key 时是离线模式，角色会用预设的可爱回复。所有数据只保存在本机浏览器（localStorage）里。
